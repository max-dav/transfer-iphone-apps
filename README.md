# Перенос приложений с iPhone на iPhone (на Mac) 22 ноября 2026 - способ рабочий

Ищет приложения в App Store, скачивает уже полученные этим Apple ID пакеты и сохраняет их в папку `загрузки` рядом со скриптом.

Скрипт не качает приложение с телефона. Он скачивает их с серверов Apple. Удалённое из магазина приложение скачивается только если этот Apple ID уже устанавливал его раньше. На старом телефоне можно подсмотреть id приложения, зажав иконку нажать на кнопку поделиться и далее в заметках вставить ссылку и в ней посмотреть (способ рабочий).

Чтобы потом залить скачанные `.ipa` на iPhone, установите бесплатную программу **Apple Configurator** из Mac App Store. Без неё файлы скачаются на компьютер, но на телефон сами не перенесутся.

## Что поставить

На Mac нужен [Homebrew](https://brew.sh). Если его ещё нет:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Нужен именно этот `ipatool` — программа [majd/ipatool](https://github.com/majd/ipatool) из Homebrew, не другие утилиты с похожим именем. Скрипт проверен с версией 2.8.1.

```bash
brew install ipatool
ipatool version
brew install python
python3 --version
```

`ipatool` обязателен. `python3` нужен, чтобы результаты поиска и покупок показывались русской таблицей. Без него скрипт тоже запускается, но печатает ответ `ipatool` как есть.

Apple Configurator ставится из Mac App Store. Эта команда открывает его страницу:

```bash
open "macappstore://apps.apple.com/app/apple-configurator/id1037126344"
```

## Запуск

```bash
chmod +x appstore.sh
./appstore.sh
```

`chmod +x` нужен один раз.

Войдите пунктом **1**. Пароль при вводе не отображается. Если Apple пришлёт код на доверенное устройство, скрипт спросит его отдельно. Первый вход может занять несколько минут.

## Меню

| Пункт | Что делает |
| --- | --- |
| 1 | Войти в App Store |
| 2 | Показать текущий аккаунт |
| 3 | Выйти и удалить сохранённый вход |
| 4 | Найти приложение |
| 5 | Список покупок этого Apple ID |
| 6 | Скачать приложение |
| 7 | Получить лицензию |
| 8 | Список версий и скачивание выбранной |
| 9 | Метаданные конкретной версии |
| 10 | Сменить платформу. По умолчанию iPhone |
| 11 | Сменить папку загрузок |
| 0 | Закрыть |

После поиска или списка покупок можно ввести номер строки. Bundle ID вводится как есть, например `ru.example.app`. Числовой ID приложения вводится с решёткой, например `#511310430`.

Файлы сохраняются в папку `загрузки` рядом со скриптом.

## Приложение удалили из App Store

Поиск по названию его не найдёт. Если Apple ID уже получал это приложение, скачивание идёт по старому числовому ID.

1. Найдите старую ссылку вида `https://apps.apple.com/app/id1234567890`. Число после `id` — это ID.
2. В пункте **6** введите `#1234567890`.
3. На вопрос о лицензии ответьте «д», если она уже должна быть на аккаунте.

Новую лицензию на удалённое приложение получить нельзя.

## Установка на iPhone

Сначала установите **Apple Configurator**, как указано выше. На телефоне должен быть тот же Apple ID, которым файл скачан.

1. Подключите iPhone кабелем и нажмите **Доверять**.
2. Откройте Apple Configurator и выберите этот iPhone.
3. Перетащите файл `.ipa` из папки `загрузки` на значок iPhone.
4. Если телефон спросит Apple ID, введите тот же, что использовался при скачивании.
